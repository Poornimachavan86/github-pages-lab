Practical implementation

Git Deployment Workflow

The major steps involved in creating, managing and publishing the website.

01 / SETUP

Create Repository

Create a public repository on GitHub for storing the project.

02 / LOCAL

Initialize Git

Create a local project folder and initialize Git tracking.

03 / DEVELOP

Create Webpage

Develop the webpage using HTML and save it as index.html.

04 / STAGE

Add Files

Use Git commands to add project files to the staging area.

05 / COMMIT

Commit Changes

Save a snapshot of the project with a meaningful commit message.

06 / CONNECT

Link Repository

Connect the local repository to the remote GitHub repository.

07 / PUSH

Upload Files

Push committed files to GitHub using the main branch.

08 / DEPLOY

Publish Website

Enable GitHub Pages and access the website through its public URL.

Understanding the Experiment

Important concepts and tools used during the practical implementation.

Tools & Technologies

  • ✓ Git – Distributed version control system.
  • ✓ GitHub – Cloud-based repository hosting platform.
  • ✓ HTML5 – Structure of the webpage.
  • ✓ GitHub Pages – Static website hosting.
  • ✓ Web Browser – Accessing the deployed website.

Important Git Commands

  • 01 git init – Initialize repository.
  • 02 git status – Check file status.
  • 03 git add . – Stage project files.
  • 04 git commit – Save changes.
  • 05 git push – Upload files to GitHub.
TERMINAL · GIT COMMANDS 
git init
git status
git add .
git commit -m "Added initial web page"
git remote add origin https://github.com/Poornimachavan86/github-pages-lab.git
git branch -M main
git push -u origin main
